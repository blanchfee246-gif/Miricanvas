# Miricanvas — 여행 경로 지도

여행지를 여러 개 입력하면 지도에 **번호가 매겨진 핀**이 찍히고, 방문 순서대로 **경로 선**이 이어져 전체 여행 동선을 한눈에 볼 수 있는 웹 앱입니다.

## 실행 방법

빌드가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.
(지도 타일과 장소 검색에 인터넷 연결이 필요합니다.)

```bash
# 또는 간단한 로컬 서버로 실행
python3 -m http.server 8000
# → http://localhost:8000
```

## 기능

- **여러 여행지 한 번에 입력** — 줄바꿈 또는 쉼표(`,`)로 구분 (예: `경복궁, 남산타워, 해운대`)
- **핀 표시** — 순서 번호가 적힌 핀, 출발지는 초록 / 도착지는 파랑
- **경로 표시** — 방문 순서대로 선을 잇고 구간마다 진행 방향 화살표 표시
- **거리 계산** — 구간별·전체 직선거리(km)
- **순서 변경** — ▲▼ 버튼 또는 드래그 앤 드롭
- **출발지로 돌아오기** — 왕복 경로(점선) 표시
- 목록 클릭 시 해당 장소로 이동, 자동 저장(브라우저 localStorage)

## 사용 기술

- [Leaflet](https://leafletjs.com/) (`vendor/leaflet`에 포함) + CARTO/OpenStreetMap 지도 타일
- [Nominatim](https://nominatim.org/) 장소 검색, 실패 시 [Photon](https://photon.komoot.io/)으로 재검색 (초당 1건씩 순차 검색)

> 장소를 찾지 못하면 `부산 해운대`처럼 지역명을 함께 입력해 보세요.
